# andrewmasker.github.io

Source for [andrewmasker.com](https://andrewmasker.com), Andrew Masker's portfolio and CV.

The site is built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme, and is deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`. For theme documentation (configuration, CV, publications, local development), see the [al-folio docs](https://github.com/alshedivat/al-folio/tree/main/docs).

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
